# Cable TV Billing — Empty Firebase Template

Blank multi-user cable billing PWA (Admin + Collector).

**No customer data included.** Connect a **new** Firebase project.

## Quick start
1. Read **SETUP.txt** (Tamil + English steps)
2. Create Firebase project + Auth + Firestore
3. Paste `firebaseConfig` into `app.js` and `collector.js`
4. Set admin email in `app.js` and Security Rules
5. Host on GitHub Pages

## Apps
| File | Use |
|------|-----|
| `index.html` | Admin |
| `collector.html` | Collector (field collection) |

## Stack
- Firebase Auth + Firestore
- Static HTML/JS (no server required)
- GitHub Pages / any static host
